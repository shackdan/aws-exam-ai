**Question 1:**  
You are working on a machine learning project that involves training a model using Amazon SageMaker. Which two of the following would be essential steps to ensure the model is trained and deployed efficiently?  

A) Setting up an S3 bucket to store the dataset  
B) Configuring AWS Lambda to trigger the model training  
C) Using Amazon EC2 instances for training the model  
D) Implementing Amazon RDS for database management  

**Correct Answer:** A, C  

**Explanation:**  
- **A) Setting up an S3 bucket to store the dataset**: This is essential as it provides a scalable and durable storage solution for your data.
- **C) Using Amazon EC2 instances for training the model**: This allows you to scale compute resources according to the needs of the training process.

**Why B and D are incorrect:**  
- **B) Configuring AWS Lambda to trigger the model training**: While AWS Lambda can be used for serverless computing, it is not directly involved in the training process.
- **D) Implementing Amazon RDS for database management**: This is typically used for relational databases and not specifically for machine learning models.
